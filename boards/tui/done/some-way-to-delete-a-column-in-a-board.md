# Description

Column headers become a focusable widget with the following keybindings:

```
r rename this column (inline Input replacing the header label)
d delete this column (confirm modal)
n create new column to the right of this one

Esc  return focus to the card list below
```

The footer hint bar swaps when  a column header is focused, same pattern as for move mode.
